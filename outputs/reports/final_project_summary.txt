6. DATA LIMITATIONS AND INTERPRETATION
--------------------------------------------------------------------
The source dataset contains time-of-day information but no complete transaction-date column.
Consequently, this project cannot establish genuine daily, weekly, or multiweek forecasts, nor can it perform chronological validation across future dates.
The Random Forest model was evaluated on a random holdout of aggregated store-hour rows. There are only 43 store-hour rows in the modeling dataset and 11 test rows.
The current R-squared score is preliminary and does not demonstrate reliable future forecasting performance.
For operational forecasting, obtain transaction dates and build a chronological dataset with sufficient history. Then compare baseline and time-series models using time-based validation.
